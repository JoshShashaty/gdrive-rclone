Privacy Policy

Last updated: November 4, 2026

Overview

gdrive-rclone is a personal application created and used solely by Josh Shashaty ("I", "me") to sync files between my own Google Drive account and my own computer using the open-source tool rclone. It is not offered to or used by anyone else.

Data accessed

The app requests access to my Google Drive so that rclone can list, download, and upload my own files. It accesses only my own Google account and the files in it.

How data is used

Data accessed through Google APIs is used only to sync files between my Google Drive and my own computer. It is not used for advertising, analytics, or any other purpose.

Storage and sharing

Files and OAuth credentials are stored only on my own devices. I do not sell, share, transfer, or disclose any data to third parties, and no data is sent to any server operated by me.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
